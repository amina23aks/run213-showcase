## My contribution

This is my second e-commerce project. I started by writing down the idea, the visual direction, and the color palette in a project planning file. From there, I built the experience step by step, starting with the frontend and expanding it into shopping, account, and admin features.

I used AI tools throughout development to plan smaller tasks, explore implementation options, work through problems, and improve the result as the project grew. I reviewed the site across its different pages and kept refining the interface and user flows.

---

## What I learned

- **Planning before coding:** Writing down the idea and visual direction helped me make more consistent decisions while building.
- **Building in stages:** Breaking a large e-commerce project into smaller features made it easier to move from the initial frontend to a more complete application.
- **Upstash and rate limiting:** I learned how rate limiting helps protect actions such as checkout from too many repeated requests.
- **Working with AI:** I learned to give AI tools clearer context, divide work into focused tasks, and review the code and behavior as I went.
- **Growing from my first store:** Building a second e-commerce project helped me approach the structure, user flows, and development process with more confidence.
