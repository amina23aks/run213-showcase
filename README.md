# 213 RUN

A streetwear shopping experience focused on clear product discovery and an easy path from browsing to checkout.

[View the live website](https://run213.vercel.app)

## What you can explore

- Browse clothing and accessories by category.
- View product details, including available colors, sizes, and stock.
- Add products to the cart and save favorites.
- Use the storefront across desktop and mobile screens.

## Behind the experience

The project also includes an admin product workflow for managing product information and availability. It uses Firebase for data and authentication, with protected API routes for administrative actions.
